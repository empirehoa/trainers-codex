## Risk register (legal/IP)

**Nintendo/TPCi enforcement pattern (verified):**
- ❌ Distributing game assets (sprites, ROMs, music) → C&D within days. Pokémon Prism (2016), Pokémon Insurgence (2024).
- ❌ Fan games using official assets → ~379 takedowns on Game Jolt (Dec 2020).
- ❌ Palworld Pokémon mods → DMCA'd Jan 2024.
- ✅ Calculator/database sites with original UI → operated 15+ years (Smogon, Marriland, PokemonDB).
- ✅ Showdown — uses original art, doesn't distribute Pokémon company assets.

**Our specific risk vectors and mitigations:**

| Risk | Mitigation |
|---|---|
| AI-generated images that look too close to Sugimori art | Prompt: "anime-style, original art direction, not based on official Pokémon artwork." Quote the prompt for evidence. |
| Printful merch with Pokémon names / official-style logos | **Never** ship merch with the word "Pokémon" on it. Use type names. Use "Trainer's Codex" branding. ✅ Already done — see `src/lib/merch.ts` slogan catalog. |
| "Pokémon" in marketing copy / store listings | Fine descriptive use in app body. **Never** in product names, store names, ad headlines. |
| Footer disclaimer | ✅ Already in `src/App.tsx:783` — "independent fan tool · not affiliated with nintendo / game freak / the pokémon company" |
| DMCA agent registration | **Action item:** register `legal@trainerscodex.com` with US Copyright Office DMCA agent directory ($6 every 3 years). Adds takedown immunity under DMCA safe harbor. |
