**First maker comment:**

Hi PH 👋 I'm Jose — this is a side project that got out of hand in the best way.

Trainer's Codex started because every team builder I tried either needed an
account, phoned home, or fell apart offline. So the whole thing is one
self-contained HTML file (~2 MB): every species, move and learnset is inlined,
it installs as a PWA, and it works on a plane.

What's in it:
• Build six from 1,307 species/forms with moves, items, shinies, Tera types
• Live defensive/offensive coverage with the dual-type math done right
• Showdown / PokePaste import + export
• 1,330 static reference pages (species, forms, types) that load zero scripts
• Journey Mode: a deterministic, seeded run-based career sim with a shared
  daily seed and a Legend Card at the end — and it's pay-neutral by design

Free tools stay free. Premium ($4.99/mo, $39/yr) unlocks cosmetic surfaces —
poster art styles, Journey archive and card finishes, more saves. Nothing
behind the paywall changes a number or a result.

It's an independent fan project, not affiliated with Nintendo, Game Freak or
The Pokémon Company. Data via PokeAPI, matchup math via @smogon/calc.

Would love to hear what a competitive player, a casual player, and a parent
handing this to a kid each find confusing. I'll be in the comments all day.
